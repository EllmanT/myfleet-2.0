# Vehicles, drivers, customers, contractors, jobs and imports

Part of the MyFleet manual QA suite. Conventions, priorities and the pass/fail procedure are in [../README.md](../README.md). Fixtures are in [../TEST_DATA.md](../TEST_DATA.md). Fill the **Result** column with PASS, FAIL, BLOCKED or N/A, and put the defect id in **Notes**. The same cases are in [../qa-tracker.csv](../qa-tracker.csv) for tracking.

Env column: **S** = run on staging/local only (it changes data or time-dependent state); **SP** = safe to run on production with a dedicated QA company.

## JOB: Jobs (create, edit, delete) (19 cases)

A "job" is one or more legs sharing a Job Number. Each leg is one row in the database and counts as ONE job in dashboard totals. Cost of a leg = rate per km x leg distance, where leg distance = next mileage minus previous mileage. There is no status field on jobs (no pending/completed); billing state is shown by invoice linkage only. Wizard: Order Details > Company Info > Preview, buttons Add Job / Edit Job, Reset.
